## Error 1 — workers.dev subdomain not registered

```
WARNING  You need to register a workers.dev subdomain before publishing to workers.dev
? Would you like to register a workers.dev subdomain now?
Using fallback value in non-interactive context: no
ERROR  You can either deploy your worker to one or more routes by specifying them in your wrangler.toml file, or register a workers.dev subdomain here:
https://dash.cloudflare.com/971830a1b105839453f92070437590be/workers/onboarding
```

Cause: the Cloudflare account has never registered its one-time `workers.dev` subdomain, and Wrangler cannot answer the prompt non-interactively.

Fix options:
1. Register the subdomain once in the dashboard, then rerun `bash worker/deploy.sh`.
2. Register it via API before deploying:
   `PUT https://api.cloudflare.com/client/v4/accounts/{account_id}/workers/subdomain` with body `{"subdomain":"<name>"}`.
3. Add a `routes` entry in `worker/wrangler.toml` and deploy to a custom domain instead.

## Error 2 — GitHub push rejected

```
remote: Invalid username or token. Password authentication is not supported for Git operations.
fatal: Authentication failed for 'https://github.com/sayed489/zero-labs.git/'
```

Cause: the supplied GitHub PAT is invalid or expired. `GET https://api.github.com/user` returns 401.

Fix: create a new fine-grained PAT with `Contents: Read and write` on `sayed489/zero-labs`, then push:

```bash
GIT_TERMINAL_PROMPT=0 git push \
  "https://x-access-token:<NEW_PAT>@github.com/sayed489/zero-labs.git" master:master
```
